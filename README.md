# ⏱ Таймер КВРМ

Лёгкое расширение для Chrome — обратный отсчёт для интеллектуальной игры КВРМ. Три игровых режима, звуковые сигналы для каждой фазы, управление с клавиатуры и аккуратный интерфейс, который подстраивается под светлую и тёмную тему системы.

Без рекламы, без аккаунтов, без сети и **без единого разрешения** в манифесте: всё, включая звуки и шрифт, хранится внутри расширения.

## Режимы

| Режим | Структура | Паузы между вопросами |
|---|---|---|
| **Вопрос** | 60 с на вопрос + 10 с на запись ответа | — |
| **Дуплет** | 2 вопроса по 30 с + 10 с на запись | После 1-го вопроса |
| **Блиц** | 3 вопроса по 20 с + 10 с на запись | После 1-го и 2-го вопросов |

В «Дуплете» и «Блице» таймер сам встаёт на паузу между вопросами и ждёт нажатия кнопки, чтобы ведущий мог спокойно зачитать следующий вопрос.

## Возможности

- **Наглядный прогресс**: кольцо с обратным отсчётом, подпись текущей фазы («Вопрос 2 из 3», «Запись ответа») и цветовые состояния: синий → оранжевый (последние секунды) → красный (запись).
- **Звуковые сигналы** для каждого события (см. таблицу ниже).
- **Горячие клавиши**: `Пробел` — старт/стоп, `1` / `2` / `3` — режимы «Вопрос» / «Дуплет» / «Блиц».
- **Доступность**: полноценная работа с клавиатуры (стрелки переключают режимы), видимый фокус, подписи для скринридеров (`role`, `aria-label`, `aria-live`), состояние не передаётся одним только цветом, пульсация предупреждения отключается при `prefers-reduced-motion`.
- **Светлая и тёмная тема** по настройке системы (Material You).
- **Офлайн**: работает без интернета.

## Звуковые сигналы

| Сигнал | Когда играет |
|---|---|
| `start` | Старт таймера и начало следующего вопроса после паузы |
| `next` | Конец вопроса (пауза между вопросами) и конец игры |
| `warning` | Осталось 10 секунд (режим «Вопрос») |
| `record` | Начало 10 секунд на запись ответа |

Все звуки — короткие синтезированные тона, встроенные прямо в `index.html` в виде `data:` URI (base64). Они **не загружаются из интернета** и не требуют отдельных файлов.

## Технологии

- **Chrome Extension, Manifest V3** — попап (`action.default_popup`), без service worker и без разрешений
- **Чистые HTML, CSS и JavaScript** — без фреймворков, сборщиков и зависимостей
- **SVG** — кольцо прогресса (`stroke-dashoffset`) и иконки
- **CSS custom properties и `prefers-color-scheme`** — темизация
- **HTML `<audio>` с base64 MP3 (`data:` URI)** — сигналы без сетевых запросов
- **Google Sans** (variable font), лежит в `public/fonts`
- **GitHub Actions** — автоматическая сборка, повышение версии и публикация релиза

Минимальная версия браузера — Chrome 111 (используется `color-mix()`), подойдёт и любой Chromium-браузер аналогичной версии.

## Релизы

Каждый push в `main` запускает workflow `Release workflow`: он повышает patch-версию в `package.json` и `public/manifest.json`, коммитит её, собирает `dist/`, упаковывает его в zip и публикует GitHub Release с тегом новой версии. Версию вручную менять не нужно.
